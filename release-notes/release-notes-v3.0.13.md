# 萌卡NT用户系统 v3.0.13

## 更新内容

- 适配框架 3.0.2，更新账号协议、节点、登录验证和等级任务的对接。
- 完善同一 QQ 的多协议账号管理、缓存重登录、删除与重新添加流程。
- 修复短信发送成功后无法确认的问题，正确显示验证手机号。
- 修复免费体验和分类变更后的授权同步，等级任务按实际结果显示状态与奖励。
- 管理员可在账号配置中生成随机指纹，创建后自动选中；普通编辑保留原有指纹。
- 修复手机短屏账号菜单滚动时意外关闭的问题，完善用户端与管理端的权限隔离。

## 升级说明

请先将框架升级至 **3.0.2 或更新版本**，本版不兼容框架 2.x。升级前备份完整数据目录与主密钥，在框架「插件 → 插件导入」上传对应系统的完整安装包并保留原数据，无需先卸载。

升级后，旧 QQ 记录若显示“待核对”，请在管理端选择对应的当前协议账号，通过“核对迁移绑定”恢复关联。用户、资金、订单与套餐历史保留；不会自动刷新已有指纹或清空登录缓存。旧 2.x Node 数据库仍需专用迁移。

# 萌卡NT用户系统 v3.0.14

## 更新内容

- 对齐框架 3.0.2 的界面风格，统一导航、页签、表格、表单、登录页与弹窗布局。
- 统一按钮尺寸、阴影、悬停、按下、焦点、禁用与加载效果，更新操作提示气泡。
- 优化手机账号卡片、搜索筛选、操作菜单及短屏弹窗，完善明暗模式显示。
- 用户门户与统一登录地址支持自动识别、自定义和恢复默认，门户设置与平台安全配置同步生效。

## 升级说明

最低支持框架 **3.0.2**，不兼容框架 2.x。升级前备份完整数据目录与主密钥，在框架「插件 → 插件导入」上传对应系统的完整安装包并保留原数据，无需先卸载。

更新完成后刷新插件页面。自定义门户域名须解析并反向代理到框架 Web 服务；门户路径仍为 `/user/`，可在其下设置自定义登录路径。

# 萌卡NT用户系统 v3.0.17

## 优化

- 适配框架 3.0.8，更新账号、套餐、接口分类和等级任务页面。
- Windows 恢复原生安装包，无需 Docker；Linux 提供 AMD64 和 ARM64 安装包。
- 优化支付网关的 IPv4／IPv6 连接和异常提示。
- 完善钱包加载失败时的提示与重试操作。

## 修复

- 修复 QQ 安全验证完成后无法继续登录的问题。
- 修复等级加速数值放大、活跃天数小数丢失，以及缺少数据时仍显示升级进度的问题。
- 修复部分等级与元宝任务的完成状态、验证提示和到期时间显示不准确的问题。
- 修复旧登录状态失效后，输入正确账号密码仍无法重新登录的问题。
- 修复注册失败后账号仍被创建，以及删除用户后同名账号无法重新注册的问题。
- 修复管理员无法将 QQ 从一个用户重新分配给另一个用户的问题。
- 修复支付网关查询失败时，无法放弃本地待支付订单或充值订单的问题。

## 升级说明

最低支持框架 **3.0.8**，不兼容框架 2.x。升级前请备份完整插件数据目录与主密钥，在框架中导入对应平台的完整安装包，保留原数据。更新完成后刷新插件页面；已有登录状态失效时重新登录。

Windows 选择 AMD64／x86_64 ZIP 包；Linux 按 Docker Engine 架构选择 AMD64／x86_64 或 ARM64／AArch64 包。旧 Windows Docker 安装需先停止插件、导出并备份数据，再按框架流程迁移至原生运行，请勿直接删除旧数据。

从旧版升级后，如页面提示账号绑定待核对，请在管理端重新选择当前框架协议，并核对迁移绑定。原有资金、订单与业务历史保留。重新注册已注销的用户名会创建独立账号；QQ 调整归属后，原用户不能继续操作该 QQ，已有业务历史仍归原用户。

放弃本地待支付订单不会关闭支付渠道订单或退款，请勿继续使用原支付链接。

# 萌卡NT用户系统 v3.0.18

## 优化

- 适配框架 3.1.3，更新插件启动、账号管理和等级任务调用。
- 等级任务显示框架返回的实际执行阶段与进度，重新打开页面后可继续查看正在运行的任务。
- 完善扫码登录、扫码授权和账号委托异常提示，便于区分权益限制、QQ 等级条件和授权状态异常。

## 修复

- 修复框架升级后，插件因旧接口失效无法启动的问题。
- 修复批量补挂任务同时提交，导致同一 QQ 的部分任务被运行冲突拒绝的问题。
- 修复电脑在线任务等待结算时被误报失败，以及未确认任务被计为已完成的问题。
- 修复 Linux 账号读取不支持的任务面板后整页加载失败的问题。
- 修复账号归属调整后，原用户的等级账号列表可能未及时更新的问题。
- 修复部分任务名称变化影响原有计划，以及小说奖励被误读为阅读时长的问题。
- 修复后续版本提高最低框架要求时，更新包被误报为缺少安装资料的问题。

## 升级说明

最低支持框架 **3.1.3**。请先升级框架，再从框架「插件 → 插件导入」直接导入 **3.0.18 完整安装包**，保留原数据。旧插件在新框架中可能无法启动，请勿依赖旧插件内部的在线安装入口。

升级前请备份完整插件数据目录与主密钥。Windows 选择 AMD64／x86_64 ZIP 包，无需 Docker；Linux 按 Docker Engine 架构选择 AMD64／x86_64 或 ARM64／AArch64 包。旧 Windows Docker 安装仍需先导出并备份数据，再按框架流程迁移，请勿直接删除旧数据。

更新完成后刷新插件页面。任务显示“等待确认”时，请先核对账号状态并刷新结果，避免重复执行。元宝身份验证需由管理员在框架等级任务页处理；框架提示账号委托校验未通过时，请核对账号与插件授权。

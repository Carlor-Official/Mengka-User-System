# 萌卡NT用户系统 v3.0.7

## 新增

- 支持 Linux 独立读取等级任务与实际等级进度。
- 展示听歌、小说和电脑在线任务的执行进度。

## 修复

- 修复新版框架导入时提示安装包资料不完整的问题。
- 修复长任务阻塞其他补挂、任务完成后误报异常的问题。
- 修复部分免费任务被隐藏、Linux 未知加速汇总显示不准确的问题。
- 修复清空自动任务后仍执行默认任务、删除 Linux 账号后遗留计划的问题。
- 修复手机端任务标签与操作控件拥挤、结果提示样式缺失的问题。

## 优化

- 自动执行时间采用 24 小时制，调整后自动保存。
- 完善会员签到条件、QQ 安全验证提示及账号权限检查。

## 升级说明

需先将框架升级至 **2.5.20 或更新版本**。升级前备份完整数据目录与主密钥，更新时保留原数据。3.0.4–3.0.6 可在线更新，更早的 3.0 版本请手动导入；更新完成后刷新管理页面。

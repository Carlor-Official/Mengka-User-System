# 萌卡NT用户系统 v3.0.8

## 修复

- 完善安装包资料校验，适配框架 2.5.21 的导入与启动检查。
- 修复新版框架提示“运行描述与安装记录不一致”的问题。
- 在线更新提前拦截缺少版本说明等必要资料的安装包。

## 优化

- 优化等级任务授权二维码的清晰度和手机端显示。

## 升级说明

请先升级框架至 **2.5.21 或更新版本**，再更新插件。升级前备份完整数据目录与主密钥。

若旧插件已报“缺少版本说明(notes)”而无法启动，请在框架「插件 → 插件导入」直接导入本版对应系统的安装包，保留原有数据，无需先卸载或删除数据目录。导入完成后若显示“已停止”，点击“启动”即可。正常运行的插件可在线更新。

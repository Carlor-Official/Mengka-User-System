# 萌卡NT用户系统 v3.0.9

## 修复

- 适配新版框架的设备指纹管理，修复提示“原生插件声明了未知 action: create_device_profile”而无法启动的问题。
- 添加 QQ 时由框架自动生成指纹，不再要求选择设备指纹；普通编辑保留原指纹与登录缓存。
- 用户门户设置显示完整访问地址，明确区分用户门户与插件管理入口，避免使用错误地址。

## 优化

- 更新管理端、用户端和登录页的样式，统一字体、主题色、表单及弹窗。
- 增加桌面页签导航，优化手机端按钮、菜单和深色模式。
- 账号编辑支持“刷新当前协议指纹”，确认后只更换该 QQ 当前协议的指纹并清除对应登录缓存。

## 升级说明

请先升级框架至 **2.7.5 或更新版本**，再安装插件。升级前备份完整数据目录与主密钥。

旧插件无法启动时，在框架「插件 → 插件导入」直接上传本版对应系统的完整安装包，核对权限变化并保留原数据。无需先卸载或删除数据目录；导入后若显示“已停止”，点击“启动”。正常运行的插件可在线更新。

升级不会自动刷新已有账号的指纹或清空登录缓存。主动刷新指纹前须将账号离线，刷新后需要重新登录。
